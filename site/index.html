// a fork of VS Code, rebuilt around a minimal Zed-style theme

An editor that doesn't
get in your way.

HappyDev takes everything VS Code already does well and strips the chrome: a dark, high-contrast theme built for long sessions, on a codebase you can actually read.

Download for macOS D Clone the repo C
macOS (Intel) available now · Windows & Linux planned
features/

Familiar underneath, different on top.

Same engine, same extension ecosystem, same keybindings you already know. What changes is what you see.

theme --apply happydev-dark

A theme built for one screen, all day

Near-black background, a single cyan accent for focus, and just enough color in the gutter to know what changed.

extensions --compatible

Every VS Code extension still works

It's the same fork underneath, so the marketplace, the debugger and the language servers you already rely on all still work.

git log --oneline -1

Open source, in public, from commit one

Every change lands as a real commit on a public repo. No private branch, no surprise release.
